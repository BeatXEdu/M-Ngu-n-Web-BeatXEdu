# BeatXEdu — Education & Open Source

BeatXEdu là trang chủ/hệ sinh thái của các công cụ học tập nhỏ gọn, gồm Bảng Tuần Hoàn, MathX và Đố Vui Hóa Học. Giao diện trang chủ lấy cảm hứng từ terminal/Linux tối giản.

## Trích Một Phần Cấu Trúc

```text
BeatXEdu/
├── index.html              # Trang chủ BeatXEdu
├── bangtuanhoan/           # Bảng tuần hoàn hóa học
├── MathX/                  # Công cụ Toán học
├── quizdovui/              # Minigame Đố Vui Hóa Học
├── khuvuc/                 # Các phân khu hệ thống/quản trị
├── netlify/functions/      # Serverless functions
├── icons/                  # PWA icons
├── manifest.json           # PWA manifest
├── sw.js                   # Service Worker
└── LICENES                 # Giấy phép & quyền tác giả
```

## Tác giả
