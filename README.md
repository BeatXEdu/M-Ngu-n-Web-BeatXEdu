# BeatXEdu — Education & Open Source

BeatXEdu là trang chủ/hệ sinh thái của các công cụ học tập nhỏ gọn, gồm Bảng Tuần Hoàn, MathX và Đố Vui Hóa Học. Giao diện trang chủ lấy cảm hứng từ terminal/Linux tối giản.

## Tác giả

- **PhuocDev (Võ Gia Phước)** — tác giả chính; kiến trúc, phát triển và triển khai.
- **NgXMath (Lê Trọng Nguyễn)** — đồng tác giả; đóng góp nội dung, ý tưởng nội dúng.

## Công nghệ

HTML, CSS, JavaScript, Netlify Functions và tích hợp Gemini API.
